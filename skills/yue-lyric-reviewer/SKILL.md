# YuE2 가사 검수

원본 `lyric-reviewer`(14항목), `pronunciation-specialist`, `voice-checker`, `explicit-checker`를 하나로 합쳤다. [공통 규칙](../yue-music/references/common-rules.md)을 먼저 적용한다. 정본 기준은 Road Music `docs/music-review.md#korean-review`다.

**검수자는 원문을 덮어쓰지 않는다.** 결과는 판정과 수정안이며, 반영은 작성자가 권한 범위에서 한다(AI 초안은 반영 후 재검수, 사용자 원문은 승인 후).

## 점검 항목

| # | 항목 | 확인할 것 |
| --- | --- | --- |
| 1 | 제목 | 제목만 읽어도 감정·장면이 전달되는가, 단어 결합·명사화·생략이 자연스러운가, 가사와 어울리는가 |
| 2 | 문장 | 조사·주어·서술어, 시제·화자·호칭, 앞뒤 줄 연결. 번역투·복원하기 어려운 생략 |
| 3 | 전곡 내용 | 누가 누구에게 무엇을 말하는가, 절·후렴·브리지의 흐름, 관계없는 비유 나열, 나/너/우리 전환 |
| 4 | 용어·비유 | 전문용어·추상어·억지 조어가 필요한가, 다른 뜻으로 읽히는가 |
| 5 | 가창 문구 | 소리 내 읽을 때 어순·호흡 무리, 운을 맞추려 비튼 문장. 실제 가창은 생성 후 검증과 구분 |
| 6 | 제목과 후렴 반복 | 문제 구절의 **모든 등장 위치**를 점검 |
| 7 | YuE2 가사 계약 | 구간 태그만 있는가, 괄호·발음 표기·화자 표시·무대 지시·`Style:` 줄이 없는가, 번호/수식어 태그가 없는가, 연주 구간 아래 가사가 없는가 |
| 8 | 구조 | `[Verse]`/`[Chorus]` 등 최소 구간, 2절이 1절의 반복이 아닌가, 훅이 있는가 |
| 9 | 절-후렴 반복 | 후렴 직전 두 줄과 후렴 첫 두 줄의 어구·이미지 중복(브리지→후렴 포함) |
| 10 | 발음 위험 | 외래어·약어·숫자·고유명사·동형어. **수정 방법은 철자 바꾸기가 아니라** 부를 형태로 쓰는 안(「3시」→「세 시」)이나 다른 단어 제안. 발음은 보장하지 않음 |
| 11 | AI 투 표현 | 추상명사 쌓기, 비유를 다시 설명하기, 상투적 고조(「영원히」「끝없이」 남발), 지나치게 대칭인 병렬, 말투 없는 완벽한 문장(원본 voice-checker 1~7류). 권고 수준 |
| 12 | 분량 | 목표 길이(기록용) 대비 지나치게 짧거나 긴가. 자르지 말고 사실만 보고 |
| 13 | 노골적 표현 | 욕설·성적 표현이 있으면 알리고 사용자 의도 확인(배포 등급 판단은 사용자) |
| 14 | 실존 곡·인물 | 기존 곡 구절 차용 의심, 실존 인물 이름. style의 실존 가수명 |

정보가 없는 항목(제목만 검토 등)은 `미확인`, 연주곡의 가사 항목은 `해당 없음`.

## 도구로 보조하기 (대체 아님)

- `lyrics:clean --json '{"text":"…"}'`: 정리본과 원문 차이(태그 변환·삭제·남은 괄호). 정리로 의미가 바뀌면 보고.
- `lyrics:check --json '{"text":"…","targetSeconds":N}'`: 분량 참고.
- `song:prepare`의 `lyrics-sections`·`lyrics-no-annotations`. 휴리스틱이므로 실제로 부르는 괄호 메아리도 표시될 수 있다 → 괄호 없이 쓰는 안을 제안.

도구 통과를 한국어 자연스러움 검수로 바꾸지 않는다.

## 수정 원칙

- AI 미확정 초안: 문제를 범위 안에서 보완하고 다시 읽는다. 자연스러운 안과 실험적인 안이 모두 가능하고 실험을 원한 근거가 없으면 자연스러운 안.
- 사용자 제공·승인 원문: `원문 → 수정안 → 이유 → 적용 여부(제안)`만. 단순 취향 차이를 필수 수정으로 올리지 않는다.
- 부분 수정 요청: 지정 구절과 반복 위치만. 범위 밖 문제는 "미적용 제안"으로 분리.
- 수정 후 전체 문맥(화자·감정·운율)을 다시 읽는다.

## 보고 형식

```text
## 제목·가사 검수
- 검수 방식: 독립 검수(에이전트) / 자체 검수(별도 단계)
- 제목 판정: 검토 완료 / 보완 필요 / 원문 보존·제안만 / 확인 불가 / 해당 없음 — 근거
- 가사 판정: (같은 값) — 주제·화자/대상·흐름 요약

| 위치 | 원문 | 수정안 | 이유(항목 #) | 적용 |
| --- | --- | --- | --- | --- |

- 남은 문제:
- 도구 점검: lyrics:clean 차이 / song:prepare 가사 점검 결과 또는 미실행
```

문제가 없으면 표에 `변경 없음`과 판단 근거를 쓴다. AI 한국어 초안에 명확한 문제가 남았거나 검수를 못 했으면 `검토 완료`로 표시하지 않고 생성으로 넘기지 않는다. 별도 에이전트가 있으면 사용자 원요청, 원문/초안 구분, 수정 허용 범위, 제목·가사, style을 넘겨 독립 검수한다.
