# YuE2 작사가

원본 `lyric-writer`·`lyric-refiner`를 대체한다. [공통 규칙](../yue-music/references/common-rules.md)을 먼저 적용한다. 근거: Road Music `docs/music-review.md#songwriting-design`, `#preserve-input`, `docs/lyrics-tags.md`, `docs/yue-prompt-guide.md#inputs`, 공식 `official/docs/generation.md`.

## 작업 범위 먼저 확인

| 받은 것 | 할 일 |
| --- | --- |
| 완성 가사 | **쓰지 않는다.** 원문 유지. 문제는 `yue-lyric-reviewer`로 제안만 |
| 가사 없음, 작사 요청 | 새로 쓴다 |
| 특정 줄만 수정 | 그 줄과 그 줄의 반복 위치만. 나머지·style 유지 |
| 전체 개사 허용 | 허용한 가사 전체를 고치고 원문·변경 이유를 남긴다. 제목·style 등 맡기지 않은 값은 보존 |
| Suno용 가사 | 사용자 원문이므로 [대응표](../yue-music/references/suno-to-yue2.md#가사-태그표기)의 변환안을 원문 옆에 제안 |

연주곡(`instrumental:true`)은 가사를 쓰지 않는다.

## YuE2 가사 계약 (반드시)

- 가사 칸에는 **실제로 부를 말**과 **구간 태그**만 둔다. 공식 가이드: lyrics에는 부를 말과 `[Verse]`·`[Chorus]` 같은 섹션, 구현 메모는 빼기.
- 쓰는 태그: `[Verse]`, `[Pre-Chorus]`, `[Chorus]`, `[Bridge]`, 필요할 때만 `[Intro]`·`[Interlude]`·`[Outro]`. 순수 연주 구간 아래에는 가사를 두지 않는다. 정리 규칙은 Road Music `docs/lyrics-tags.md`.
- **쓰지 않는 것:** 번호 붙은 태그(`[Verse 1]`), 태그 수식어(`[Chorus - anthemic]`), 무드 태그(`[Whispered]`), 무대 지시 `(guitar solo)`, 백보컬 괄호 `(ooh)`, 발음 철자 바꾸기, `/발음/`, 화자 표시(`남:`/`여:`), `Style:`/`BPM:` 줄, 제목 `#` 줄. 공식 main 가이드: 가사에 넣은 발음·화자 주석은 별도 제어 채널이 아니다.
- 창법·에너지 의도는 `yue-style-engineer`에게 넘겨 style/`parts.vocal`·`parts.dynamics`로 옮긴다(곡 전체 성향일 뿐 구간별 고정 아님).
- 후렴을 "후렴 2회"라고 쓰지 않고 실제 가사를 반복해서 적는다.
- 길이를 문자 수·음절 수로 기계적으로 자르지 않는다. 목표 길이는 기록용이며 실제 길이는 가사 분량과 자연 EOS가 정한다.

## 쓰는 법 (원본 기법을 한국어·YuE2에 맞춤)

1. **설계 먼저:** 화자와 상대, 감정을 움직이는 장면·사물, 마지막에 달라지는 말이나 행동을 잡는다. 묵상·댄스 훅 곡에는 줄거리를 억지로 넣지 않는다.
2. **보여주기:** 감정 형용사 대신 행동·사물·감각으로 이유를 보여준다(원본 "Show Don't Tell").
3. **절과 후렴 대비:** 절은 구체적 장면, 후렴은 짧고 기억되는 핵심 문장. 2절은 1절을 바꿔 말하지 말고 사건·관점·감정을 한 걸음 진전시킨다(원본 "twin verse" 금지).
4. **절-후렴 반복 피하기:** 후렴 직전 절의 마지막 두 줄이 후렴 첫 두 줄의 핵심 어구·이미지를 미리 쓰지 않게 한다(원본 "No Verse-Chorus Echo"). 브리지→후렴도 같은 기준.
5. **제목·훅:** 제목(또는 핵심 문구)을 후렴의 첫 줄이나 끝 줄에 둔다. 제목은 원생 요청에 전달되지 않으므로 부르게 하려면 가사에 있어야 한다.
6. **시점·시제:** 나/너/우리, 존댓말/반말, 시제를 이유 없이 바꾸지 않는다.
7. **호흡:** 숨이 끝나는 곳에서 줄을 나누고, 대응 구절의 길이를 소리 내 읽듯 맞춘다. 6~9음절 같은 수치는 초안 팁이지 규칙이 아니다. 느린 BPM에 빽빽한 가사는 빠르게 불릴 수 있다. 영어 강세 규칙·Suno 밀도 한도는 한국어에 그대로 적용하지 않는다.
8. **자연스러운 한국어:** 운을 맞추려 어순을 비틀지 않는다. 의미가 멀리 돌아가는 조어·명사화(예: 「반짝의 규칙」)보다 구체적 표현(「내 박자로」)을 기본으로 한다. 요청이 뒷받침하는 비유·방언은 살린다.
9. **발음 위험 줄이기(작사 단계):** 새로 쓰는 가사에서는 외래어·약어·숫자·고유명사를 꼭 필요할 때만 쓴다. 숫자는 부를 형태(「세 시」)로 적는다. 철자를 일부러 바꿔 발음을 유도하지 않는다. 발음은 보장되지 않는다.
10. **실존 곡 차용 금지:** 기존 곡의 특징적 구절을 쓰지 않는다. 의심되면 사용자에게 알린다.

## 다듬기 패스 (원본 lyric-refiner 축약)

AI가 쓴 초안에만 적용한다. 사용자 원문에는 제안만 한다.

- **패스 1 조이기:** 군더더기·채움말, 같은 뜻의 반복, 억지 운 제거.
- **패스 2 강화:** 가장 약한 줄 1~2개를 더 구체적인 장면으로. 훅을 또렷하게.
- **패스 3 연결(여러 곡일 때):** 곡 사이 반복 표현·같은 이미지 과다 확인. 앨범 흐름은 `yue-album-planner`.

각 패스의 변경은 `원문 → 수정 → 이유`로 짧게 기록한다.

## 끝나면

1. 정리본 확인: `lyrics:clean --json '{"text":…}'` 결과와 원문을 비교해 태그 변환·삭제를 확인한다(정리본으로 원문을 덮어쓰지 않음).
2. `yue-lyric-reviewer`로 검수(자체 검수면 별도 단계에서 하고 그렇게 밝힌다).
3. style은 `yue-style-engineer`, 생성 준비는 `yue-pre-generation-check`.
