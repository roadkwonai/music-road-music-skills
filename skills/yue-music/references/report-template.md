# 보고 형식

Road Music `docs/yue-prompt-guide.md#official-report`의 형식을 그대로 따른다. 제목과 표 열 이름을 바꾸지 않는다.

## YuE2 공식 가이드 보정 보고 (매번 필수)

```text
## YuE2 공식 가이드 보정 보고
- 참고 원문: 공식 yue2-v0.1.6 generation·generation-and-covers, main(1116bea, 2026-11-01) generation, (yue-mlx면) MLX usage, 엔진 yue-mlx
- 공식 점검(song:prepare officialGuide): pass N · advice N · 해당 없음 N

| 항목 | 원래 입력 | 보정 후 | 공식 근거 | 적용 |
| --- | --- | --- | --- | --- |
| style 언어 | (원문) | Korean, ... | style에 언어 기재 | 적용 / 제안(승인 대기) / 유지(이유) |

- 최종 style 구성: 언어 / 장르 / 보컬 / 악기 / 분위기·프레이징 / BPM
- 가사 구성: 구간 태그 순서, 주석·지시문 처리, 정리(cleanLyrics) 전후 차이
- 모드·옵션: cot, seed, abc 유무, 기본값 유지 또는 변경 이유
- 보장하지 않는 것: 특정 가수·발음·정확한 템포와 길이·무보컬은 청취로 확인
```

작성 규칙:

- 보정할 것이 없으면 표에 `보정 없음` 한 줄과 통과한 점검 ID를 적는다. 절 자체를 생략하지 않는다.
- `적용` 열: AI 작성분은 `적용`, 사용자 원문은 `제안(승인 대기)` 또는 승인 후 `적용(승인)`, 의도적으로 남긴 advice는 `유지(이유)`.
- `song:prepare`를 실행하지 못했으면 점검 줄을 `미실행(사유)`로 적고 정적 점검 결과만 쓴다.
- 보정 뒤 다시 `song:prepare`를 실행한 결과(남은 advice 수)를 적는다.
- `officialGuide`는 문자열 휴리스틱이다. 예: 실제로 부르는 메아리 `(사랑해)`도 주석으로 표시될 수 있다. 이런 경우 `유지(실제 가창 문구, 괄호 없이 쓰는 안 제안)`처럼 이유를 적는다.

## 생성 전 검토안 (기본 검토 모드)

`docs/music-review.md#proposal`의 항목을 한 번에 보여주고 승인을 기다린다.

| 항목 | 내용 |
| --- | --- |
| 곡 사양 | 제목·엔진·장르·보컬·언어·목표 길이(기록용)·BPM·악기·곡 수, 가정값 표시 |
| 가사 | 실제 전달할 전체 가사(정리본)와 원문 차이. 연주곡은 가사 없음 |
| 한국어 검수 | 제목·가사 판정, 위치·원문·수정안·이유·적용 여부, 남은 문제, 독립/자체 검수 |
| 프롬프트 | 원래 `style`/`parts`와 `song:prepare`의 최종 style |
| 옵션 | 실행할 요청 JSON 전체 |
| 검증 | `song:prepare` `valid`, notes, `changes`, 실효 옵션 |
| 근거 | 실제로 읽은 문서 절, 장르 출발점, 선택 이유 |
| YuE2 공식 보정 | 위 보정 보고 절 |

마지막에 한 번 묻는다: "이 가사·프롬프트·옵션으로 생성할까요? 수정할 부분이 있으면 알려주세요."

## 생성 후 결과 보고

| 자료 | 내용 |
| --- | --- |
| 음악 | 실제 오디오 절대 경로(`job:wait`·`songs:list` 응답 그대로). 채팅이 지원하면 오디오 첨부 |
| 가사·프롬프트·설정 | 실제 전달 가사, 최종 style, 요청 JSON, seed, 엔진, 실효 advanced·runtime(정밀도 포함), 모델/VAE·런타임 리비전(결과에 있을 때) |
| 참고 자료·선택 이유 | 실제로 읽은 문서 절, 장르 레시피, 조사 URL·확인일, 보컬·악기·구조를 고른 이유 |
| 파일 검사 | 실제 길이·포맷, `result.json`의 `truncated.abc`·`truncated.semantic` |
| 가사 반영 | 자동 전사(사용한 모델·무유도 여부) / 직접 청취 / 확인 불가를 구분 |
| 한국어 검수·보정 보고 | 위 두 절 |
| 한계 | 목표 길이 대비 실제 길이, 미청취 항목 |
