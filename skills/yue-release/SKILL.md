# YuE2 곡 공개·배포 준비

원본의 `release-director`·`promo-writer`·`promo-reviewer`·`album-art-director`·`plagiarism-checker`·`explicit-checker`를 Road Music YuE2 결과물 기준으로 합쳤다. Suno 약관 대신 **YuE2 코드·모델 라이선스와 Road Music 권리 규칙**을 기준으로 삼는다. [공통 규칙](../yue-music/references/common-rules.md)을 적용한다.

이 스킬은 준비와 점검까지 한다. **업로드·게시·배포 신청·SNS 게시·외부 전송은 사용자가 직접 하거나 그 행동마다 명시적으로 승인한 경우에만** 한다. 답변에도 "업로드·게시는 하지 않았다"고 밝힌다. 법률 자문이 아니며, 상업 이용 여부가 불분명하면 사용자가 최신 공식 조건이나 전문가를 확인하도록 안내한다. 납품물 파일은 Road Music 곡 보관 폴더(Songs와 그 아래) **밖**의 작업 폴더에 둔다(`songs:list`가 프로젝트 안의 오디오 없는 하위 폴더를 정리하기 때문).

## 1. 권리·라이선스 점검 (필수)

근거: Road Music `docs/yue-prompt-guide.md#rights`, `docs/vendor/yue2/README.md`, `docs/vendor/yue2/official/LICENSE`·`official/MODEL_LICENSE`, `docs/vendor/yue2/current/LICENSE`·`current/MODEL_LICENSE`, `docs/vendor/yue2/mlx/LICENSE`. **실제로 읽은 원문만** 근거로 쓰고 파일 경로를 함께 적는다.

| 항목 | 확인할 것 |
| --- | --- |
| 코드·문서 라이선스 | 고정판 yue2-v0.1.6 코드·문서는 CC BY-NC 4.0, 공식 main은 Apache-2.0, MLX 포트 코드는 Apache-2.0. **생성물을 쓸 수 있는지는 이것이 아니라 모델 가중치 조건으로 판단한다** |
| 모델 가중치 라이선스 | 기본 조건은 CC BY-NC 4.0(비상업). Road Music이 고정한 가중치에 동봉된 LICENSE에는 개인 추가 허락이 **없다**. 조사 시점 공식 main의 `MODEL_LICENSE`에만 **개인 사용자·창작자·음악가**가 responsible-use 조건을 지키면 생성물 수익화를 허용하는 추가 조항이 있다(YuE2-3B·Vae 가중치 대상, HF 리비전 열거 없음). 이 조항이 설치된 리비전에 적용되는지, 사용 주체(개인/회사)·목적에 맞는지는 사용자가 최신 공식 조건으로 확인하게 한다. 회사의 상업 이용·가중치 재배포로 넓히지 않는다 |
| 크레딧 | 모델 라이선스의 크레딧 표기는 권고이며 조건이 아니다. 플랫폼의 AI 고지 의무와는 따로 다룬다 |
| 입력의 권리 | 사용자가 준 가사·번역·원곡 선율(커버)·참조 녹음의 권리. 원전이 만료된 찬송가도 현행 번역 가사·편곡·녹음은 별도(`docs/hymn-remake-guide.md`). 커버에 SheetSage2를 썼다면 그 가중치도 CC BY-NC 4.0 |
| 제3자 권리 | 생성물의 저작권 성립·독점권·제3자 권리 비침해를 보장하지 않는다. 특정 인물 목소리처럼 들리는 결과는 공개하지 않는 쪽을 권한다 |
| AI 생성 고지 | 배포처의 현재 AI 고지 정책을 실행일에 확인하도록 안내하고(확인한 페이지 링크를 적는다), 설명란·크레딧 고지 문구 안을 제시 |

## 2. 콘텐츠 점검

- **실존 곡 차용:** 웹 검색으로 대조하려면 **미공개 가사 구절을 외부 검색 서비스에 보내는 것**이므로 먼저 사용자 동의를 받는다(전체 자동 위임이면 제목·후렴 첫 줄 정도로 범위를 줄이고 보고). 결과는 `낮음/확인 필요/높음`과 근거 링크로. 검색하지 않았으면 미실행이라고 쓴다. 차용이 의심되면 개사 제안만 하고 원문은 사용자가 정한다.
- **노골적 표현:** 욕설·성적·폭력 표현 유무와 배포처 Explicit 표기를 맞춘다.
- **실존 인물·사실:** 사실 기반 곡이면 `yue-research`의 사람 확인과 최종 가사의 사실 문장 일치를 본다.
- **가창 결과:** 승인된 가사를 실제로 불렀는지는 `yue-result-review` 판정을 따른다. 미청취·확인 불가를 "검수 완료"로 쓰지 않는다.

## 3. 납품물 준비

| 납품물 | 만드는 방법 |
| --- | --- |
| 마스터 음원 | `yue-mastering` 결과(원본 보존) |
| 가사 파일 | 실제 전달한 가사에서 구간 태그를 뺀 텍스트. 원가사를 임의 수정하거나 ASR 전사로 대체하지 않는다 |
| 자막 | YuE 곡에는 Road Music `song:lrc`용 `lyrics.lrc`가 없다(ACE 전용). `song:srt`는 악보 박자 기반 추정이거나 악보가 없으면 곡 길이를 균등 분할한 것이므로 실제 가창과 어긋날 수 있다. 저장은 `--output FILE`. 타이밍은 청취로 맞춘 뒤 쓴다 |
| 메타데이터 | 제목(사용자 표기 그대로), 아티스트명, 앨범명, 트랙 번호, 장르, 발매일, 언어, Explicit, 작사·작곡 크레딧(사람이 쓴 가사는 사람 크레딧), AI 사용 고지. 모르는 값은 빈칸으로 두고 묻는다 |
| 커버 아트 브리프 | 장면·색·분위기·텍스트 배치. 실존 인물·상표·다른 앨범 아트를 흉내 내지 않는다. 생성은 사용 가능한 이미지 도구나 사용자에게 맡긴다 |
| 설명란·홍보 문구 | 플랫폼별 짧은 소개 초안. 곡에서 확인된 사실만, 과장 표현은 줄인다. 게시는 사용자 몫 |
| 영상 | 유튜브는 오디오만 올릴 수 없으므로 정지 이미지·영상과 합친 파일이 필요하다. Road Music 영상 스킬(`road-music-video-studio`, `road-music-showreel-*`, 저장소의 `road-music-mv` 등 이 환경에 설치된 것)을 쓰고, 없으면 미사용으로 적는다 |

플랫폼별 규격·정책은 바뀌므로 실행일에 공식 안내를 확인하고, 확인하지 못한 수치를 쓰지 않는다.

## 4. 배포 체크리스트

```text
## 공개 전 점검
- [ ] 권리: 사용 주체·목적, 모델 가중치 조건(읽은 원문: …), 코드 라이선스와 구분
- [ ] 입력 권리: 가사·번역·커버 원곡·참조 녹음·SheetSage2
- [ ] AI 생성 고지(확인한 플랫폼 안내 링크)
- [ ] 차용 점검: 결과 / 미실행(동의 없음)
- [ ] Explicit 표기
- [ ] 사실 기반 곡: 출처 사람 확인·가사 사실 문장 일치
- [ ] 최종 음원: truncation 없음, 길이·포맷, 청취 여부
- [ ] 마스터링: 목표 LUFS/TP, 원본 보존
- [ ] 메타데이터·크레딧·가사 파일·자막(추정 여부)
- [ ] 커버 아트·설명란·영상
- 게시: 하지 않음(사용자 직접)
```

## 5. 공개 후

사용자가 게시 링크를 알려주면 제목·가사·크레딧 표기를 대조하는 점검을 도울 수 있다. 콘텐츠 ID 분쟁·권리 주장 대응은 해당 플랫폼 절차와 필요하면 전문가 확인을 안내한다. 공개 준비 단계를 Road Music 제작 기록에 남기려면 같은 곡 `requestId`로 `review` 작업을 기록한다.
