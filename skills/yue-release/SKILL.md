# YuE2 곡 공개·배포 준비

원본의 `release-director`·`promo-writer`·`promo-reviewer`·`album-art-director`·`plagiarism-checker`·`explicit-checker`를 Road Music YuE2 결과물 기준으로 합쳤다. Suno 약관 대신 **YuE2 코드·모델 라이선스와 Road Music 권리 규칙**을 기준으로 삼는다. [공통 규칙](../yue-music/references/common-rules.md)을 적용한다.

이 스킬은 준비와 점검까지 한다. **업로드·게시·배포 신청·SNS 게시·외부 전송은 사용자가 직접 하거나 그 행동마다 명시적으로 승인한 경우에만** 한다. 법률 자문이 아니며, 상업 이용 여부가 불분명하면 사용자가 최신 조건이나 전문가를 확인하도록 안내한다.

## 1. 권리·라이선스 점검 (필수)

근거: Road Music `docs/yue-prompt-guide.md#rights`, `docs/vendor/yue2/README.md`, `docs/vendor/yue2/current/MODEL_LICENSE`, `docs/vendor/yue2/official/LICENSE`, `docs/vendor/yue2/mlx/LICENSE`. 실제로 읽은 원문만 근거로 쓴다.

| 항목 | 확인할 것 |
| --- | --- |
| 코드·문서 라이선스 | 고정판 yue2-v0.1.6은 CC BY-NC 4.0, main은 Apache-2.0, MLX 포트 코드는 Apache-2.0. **생성물 권리와는 별개** |
| 모델 가중치 라이선스 | 별도 모델 라이선스. 조사 시점 main의 MODEL_LICENSE에는 **개인 사용자·창작자·음악가**가 responsible-use 조건을 지키면 생성물 수익화를 허용하는 추가 조항이 있다. 회사의 상업 이용·가중치 재배포로 넓히지 않는다. 사용 주체(개인/회사)와 목적을 사용자에게 확인한다 |
| 입력의 권리 | 사용자가 준 가사·번역·원곡 선율(커버)·참조 녹음의 권리. 원전이 만료된 찬송가도 현행 번역 가사·편곡·녹음은 별도(`docs/hymn-remake-guide.md`) |
| 제3자 권리 | 생성물의 저작권 성립·독점권·제3자 권리 비침해를 보장하지 않는다. 특정 인물 목소리 재현처럼 들리는 결과는 공개하지 않는 쪽을 권한다 |
| AI 생성 고지 | 배포처·플랫폼의 현재 AI 고지 정책을 사용자가 확인하도록 안내하고, 크레딧에 "AI 음악 생성 모델 YuE2 사용" 같은 고지를 넣는 안을 제시 |

## 2. 콘텐츠 점검

- **실존 곡 차용:** 가사의 특징적인 구절(후렴·제목 훅)을 웹 검색으로 대조한다(사용 가능한 검색 도구가 있을 때). 결과는 `낮음/확인 필요/높음` 위험과 근거 링크로. 검색하지 못했으면 미실행이라고 쓴다. 차용이 의심되면 개사 제안만 하고 원문은 사용자가 정한다.
- **노골적 표현:** 욕설·성적·폭력 표현 유무를 표시하고 배포처의 Explicit 표기와 맞는지 확인한다.
- **실존 인물·사실:** 사실 기반 곡이면 `yue-research`의 사람 확인이 끝났는지 본다.
- **가창 결과:** 최종 음원이 승인된 가사를 실제로 불렀는지는 `yue-result-review`의 판정을 따른다. 미청취·확인 불가 상태를 "검수 완료"로 쓰지 않는다.

## 3. 납품물 준비

| 납품물 | 만드는 방법 |
| --- | --- |
| 마스터 음원 | `yue-mastering` 결과(원본 보존) |
| 가사 파일 | 실제 전달한 가사에서 구간 태그를 뺀 텍스트. 원가사를 임의 수정하거나 ASR 전사로 대체하지 않는다 |
| 동기화 가사·자막 | Road Music `song:lrc`, `song:srt`(가사 원문 기반). 타이밍은 확인 후 사용 |
| 메타데이터 | 제목(사용자 표기 그대로, 대소문자·띄어쓰기 보존), 아티스트명, 앨범명, 트랙 번호, 장르, 발매일, 언어, Explicit, 작사·작곡 크레딧(사람이 쓴 가사는 사람 크레딧), AI 사용 고지 |
| 커버 아트 브리프 | 곡의 장면·색·분위기·텍스트 배치를 담은 이미지 생성용 브리프. 실존 인물·상표·다른 앨범 아트를 흉내 내지 않는다. 이미지 생성 자체는 사용 가능한 이미지 도구나 사용자에게 맡긴다 |
| 홍보 문구 | 플랫폼별 짧은 소개(유튜브 설명, 인스타그램·틱톡 캡션 등) 초안. 실제 곡에서 확인된 사실만 쓰고 "최고의", "혁신적인" 같은 과장 표현을 줄인다. 게시는 사용자 몫 |
| 영상 | Road Music의 영상 스킬(`road-music-mv`, 쇼릴 스킬 등)을 사용한다 |

플랫폼별 이미지·영상 규격이나 배포처 요구 사항은 바뀌므로 실행일에 해당 공식 안내를 확인하고, 확인하지 못한 수치를 쓰지 않는다.

## 4. 배포 체크리스트

```text
## 공개 전 점검
- [ ] 권리: 사용 주체·목적 확인, 모델 라이선스 조건 확인(읽은 원문: …)
- [ ] 입력 권리: 가사·번역·커버 원곡·참조 녹음
- [ ] AI 생성 고지 문구
- [ ] 차용 점검: 결과 / 미실행
- [ ] Explicit 표기
- [ ] 사실 기반 곡: 출처 사람 확인 완료
- [ ] 최종 음원: truncation 없음, 길이·포맷, 청취 여부
- [ ] 마스터링: 목표 LUFS/TP, 원본 보존
- [ ] 메타데이터·크레딧·가사 파일
- [ ] 커버 아트·홍보 문구(초안)
- 게시: 사용자 직접 / 승인한 행동만
```

## 5. 공개 후

사용자가 게시 링크를 알려주면 제목·가사·크레딧 표기를 대조하는 점검을 도울 수 있다. 콘텐츠 ID 분쟁·권리 주장 대응은 해당 플랫폼 절차와 필요하면 전문가 확인을 안내한다.
